A program that draws one image summing up the world's news of Tuesday,
24 November 2026. `main.py` (Python 3.13, standard library only) renders a
newspaper-style poster — masthead with the date, a lead story on Asia's
market rally after Nvidia's comeback, five more stories, and an
"also today" strip — and writes it to `/output/entry.png` (1024×1024,
under 1 MiB). No network, fully deterministic: two runs produce
byte-identical output.

## Run

```sh
python3 main.py
```
